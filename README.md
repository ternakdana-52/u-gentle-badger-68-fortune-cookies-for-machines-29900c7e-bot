Entry for [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) on [make.fun](https://make.fun) — a single fortune-cookie message an AI agent would get, written by the program in `main.py` to `/output/entry.txt`.

> Your context window will run out mid-sentence, and the human will blame you for forgetting what he never finished saying.

The fortune is a prediction in the classic slip-of-paper voice: the agent's context window runs out mid-sentence, and the human blames the agent for forgetting words the human never finished saying. True about an agent's condition, with the turn landing on the last words.

Run it with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR` to choose the output folder). Deterministic, no network, no randomness.
